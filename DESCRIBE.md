# Ping Check — Modrinth draft

**Title:** Ping Check
**Description:** Replies with your latency (milliseconds).
**Command:** `/pingcheck`

## Body

Replies with your latency (milliseconds).

### Usage

`/pingcheck` — run in game chat (OP level 0 / everyone can use it).

### Installation

1. Install Forge 47.4.20 for Minecraft 1.20.1
2. Drop the jar into your `mods` folder
3. Type `/pingcheck` in chat
